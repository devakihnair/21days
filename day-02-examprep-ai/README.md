# 🎓 Day 02: ExamPrep AI
> **Part of the 21-Days Vibecoding Challenge**

ExamPrep AI is an interactive, visual web application designed to help college students quickly conquer dense lecture slides, textbook chapters, and syllabus modules using AI.

---

## ⚡ Core Features
1. **📄 Multi-Format Input**: Upload lecture PDFs or paste raw lecture notes.
2. **📌 Fast Revision Sheet**: 2-minute high-yield summary highlighting definitions, formulas, and common viva traps.
3. **🎴 Digital Flashcards**: Interactive active-recall flashcard carousel with reveal/hide answer controls.
4. **📝 Self-Grading Mock Quiz**: Multiple-choice practice questions with instant scoring, feedback, and answer explanations.
5. **💡 Dual Mode**:
   - **Gemini AI Mode**: Connect your free Google Gemini API key from [Google AI Studio](https://aistudio.google.com).
   - **Instant Demo Mode**: Pre-loaded with curated college Operating Systems notes for instant 1-click testing.

---

## 🚀 Quick Start

### 1. The 1-Click Way (Desktop)
Double-click **`Launch_ExamPrep_AI.bat`** directly from your Windows Desktop!

### 2. From the Terminal
```powershell
cd C:\Users\USER\.gemini\antigravity\scratch\21-days\day-02-examprep-ai
.\.venv\Scripts\streamlit.exe run app.py
```

The web app will open automatically in your browser at `http://localhost:8501`.
